    Questions

    Is this a real ATS score?

    No. This is a transparent Canopy estimate based on detected text, keywords and resume structure. Different employers use different systems and criteria.

    Can it inspect visual formatting?

    No. This version checks extracted text and section structure. It cannot reliably judge columns, fonts, spacing, graphics or visual hierarchy.

    Is my resume uploaded?

    Resume file parsing happens in your browser. If you choose to save a screening, only summary information is sent to your Canopy backend.

    Can it replace a recruiter?

    No. Keyword matching can miss equivalent skills and context. Use results as guidance, not as an automated hiring decision.
